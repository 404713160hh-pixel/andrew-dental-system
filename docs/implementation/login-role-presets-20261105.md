# 登录角色与账号选择

2026-11-05

员工登录页展示四个角色及对应演示账号：总部管理员 `hq`、店长 `manager.a`、前台 `front.a`、医生 `doctor.a`。点击角色填入员工账号，仍需输入密码。支持键盘选择和手动输入其他员工账号；账号手动改为其他值时，角色选中态随之取消。

小程序登录页明确为患者入口，展示患者A `patient.a` 和患者B `patient.b`，点击后仅填入账号。患者注册、关联已有档案及隐私授权保留。切换到注册或关联档案时，清除演示账号，避免误注册已存在的账号。

两端切换身份时清除旧密码和错误信息，正在登录时禁止切换。角色卡片不保存密码、不提交角色权限，也不自动登录。网站仍提交 `portal: staff`，小程序仍提交 `portal: patient`，后端决定账号权限；生产环境的免密码演示登录保持关闭。

验证结果：

- 员工端 46 项、小程序 49 项模块测试通过，两端类型检查及生产构建通过。
- 本地浏览器在 1440px 和 390px 验证四个角色自动填入、选中态、手动输入、键盘操作、旧密码清空和无横向溢出。表单提交检查使用拦截的失败回执，确认普通密码登录请求未改变。
- 微信开发者工具 390px 原生页面验证患者A/B点击填入、切换清空旧密码、手动输入清除选中态；没有提交真实登录或修改原有会话。
- 小程序生产构建使用 `https://andrewdental.top/api/v1`，同步到 `D:\AndrewDentalMiniProgram` 时保留 AppID 与合法域名校验配置。
