## 客户端会话竞态补充验证

在上述 12 项真实浏览器验收之后，补充修正了跨账号请求竞态：请求发出时捕获其 token，只有返回 401 时该 token 仍是当前 token，才清除会话并通知登录失效。账号 A 的迟到响应不会撤销随后登录的账号 B。待确认命令也捕获发出时的主体存储键，异步完成时只清除该主体的记录。

`npm run test -w @andrew/admin-web` 运行四项隔离客户端单元测试：A 迟到 401 保留 B、当前 token 的 401 正常清除、A 迟到成功只清 A 的命令、A 迟到 401 保留两个主体各自的待确认命令。测试加载实际 `api.ts`，通过受控的网络返回时序核验会话与存储行为。这里的受控传输属于客户端单元测试，**不计入前述 12 项真实 HTTP/浏览器验收**。
