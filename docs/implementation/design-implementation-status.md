# 设计与开发现状核对

核对日期：2026-11-06。设计依据为 [系统设计文档 PDF](../design/1602240215.pdf)，页数及哈希见[交付清单](../design/delivery-manifest.json)。代码依据为 `booking-api/`、`admin-web/`、`miniprogram/`、`shared/` 和 `database/migrations/`。本轮补齐员工资料和原始案例要求的医生季度业绩与10%激励基金，按实际迁移同步该模块用例、类图、业务与内部序列、状态及字段字典。
