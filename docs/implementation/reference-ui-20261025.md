## 小程序

- 保留门诊、服务、日期、医生四个原生选择器，增加七日快选和弹出日历；日期选择不等于有号，仍须向后端查询。
- `/booking-policy` 返回现有查询范围的 `queryWindow.fromDate/toDate`。日历和原生日期控件共用这份范围，没有在两个前端另写固定天数。后端原来的日期判断边界保持不变，历史占位与预约规则快照也不改变。
- 已返回号源按北京时间分成上午、下午、晚间。分组保存原始数组索引，点击时仍向同一个后端提交原号源；不通过分组计算容量。
- 目录加载失败、查询失败、成功但无号分别展示。目录失败可原地重试；切换筛选或离开页面后，迟到的旧回包不能重新填入旧时段。
- 确认、改期、取消仍由真实命令结果反馈；结果不明继续使用原操作标识核对。组件升级没有增加本地假成功、支付或独立预约数据。

## 员工网站

- 预约和排班均增加前一天、今天、后一天和七日日期条；窄屏自动将选中日期滚入日期条，用户仍可手动横滑。
- 预约可在列表与按医生分组的日程间切换。日程逐页取得当前筛选数据，核对总数、重复记录与头页版本；记录变化或未加载完整时明确提示，不把某一页当作全天。
- 排班可切为医生卡片。展示的是本次查询记录，明确服务端 500 条上限，不把查询数量称为可约容量。
- 保留可见页面的自动同步、详情读取和原有管理操作。请求世代与账号检查防止旧日期、旧门诊或旧账号的结果覆盖当前页面。
- 医生看“我的预约”“我的排班”和“仅本人”范围；总部、店长、前台继续按后端权限操作。
- 可按账号保存紧凑/舒适视图；手机侧栏可展开、跳转后收起。工作页移除大幅宣传横幅，让日期、筛选与日程更靠前。
- 资源页常驻显示范围、名称筛选、匹配与总计；资格展示完整生效与失效日期，并区分未生效、生效中、已过期。展示状态不替代服务端对完整班次的资格复核。

## 构建与复测

从仓库根目录安装依赖、构建，并同步到现有开发者工具工程：

```powershell
npm ci
npm run check:booking
npm run build:booking
npm run sync:wechat
```

`D:\AndrewDentalMiniProgram` 是本机工具运行目录。同步前自动备份，保留 AppID 和本地工具配置，核对源码及编译产物哈希。所有开发修改仍在仓库维护。
