# 小程序功能布局调整

2026-11-05

首页以横幅、两个主要入口、四个快捷功能、医生缩略卡和预约服务列表组织内容。主要入口为“在线预约”和“门诊位置”；快捷功能为“医生团队”“项目参考”“我的预约”“就诊资料”。底部导航为“首页 / 门诊 / 预约 / 我的”，不设会员模块。

新增门诊页复用公共 `/api/v1/clinics` 数据，展示照片、地址、营业时间和电话，可复制地址、查看该门诊医生和查询该门诊号源。两家演示门诊使用不同图片。虚构地址不生成地图坐标，虚构电话明确标记并禁用拨打；真实记录在有电话号码时可拨打。

医生、项目、登录和预约等页面删除英文装饰、宣传标题与重复说明；保留必要字段、操作结果、预约规则、隐私授权、虚构资料标识以及参考费用说明。医生肖像和展示简称不改变后端原始身份数据。

首页“在线预约”入口在未登录时进入登录页。门诊、医生和号源仍可公开浏览；预约占位、确认、取消和改期继续使用原有后端权限与事务规则。
