# 中南大学中文报告版式

将参考格式应用于整份文档，正文、图表、参考文献和附录与封面一并处理。报告主题、章节和业务内容由当前任务决定，不套用原调研报告或牙科项目的内容。

## 使用资料

- 开始排版时读取 [版式规范](references/format.md)，包含准确字号、间距、页眉页脚与分页约定。
- 新建TeX/PDF时使用 [可编辑底稿](assets/report-template.tex) 和校标文件；底稿正文是简短版式示例，正式制作时替换整个示例正文。
- 沿用本人署名时参考 [个人信息使用规则](references/personal-profile.md)，当前用户给出的字段优先。
- 仅在制作系统分析与设计模型图时读取 [模型图排版](references/system-diagrams.md)。其中UML语义约定与通用报告版式分开。
- 原参考源码保存在 [source-report.tex](references/source-report.tex)，用于比对序言和版式。其旧主题、结论、调研数据及教师姓名不进入新报告；原稿全部配图未收录，编译入口是可编辑底稿。

## 制作与修改

1. 沿用任务已确定的内容和交付格式。标题、文档类别、可选副标题、学院、班级、学号、姓名、教师及页眉简称均可配置。默认不加课程项目标签、版本号或年月装饰；日期保留于确有需要的引用和数据说明中。
2. 新建报告可运行 `scripts/new_report.py --out <新目录> --title <题目> --author <姓名>`，其他参数见 `--help`。脚本复制底稿和校标、转义普通文本字段，随后编辑生成的 `report.tex` 正文。修改既有文档时直接调整其格式与必要的图形布局，保留正文，不用新建脚本覆盖原文件。
3. 所有页面使用竖向A4。宽图要重新布局、合理分组或分成有连续标题的子图，保持字可读；图号和图题位于图下。表格采用三线表，跨页表重复表头，编号如UC-01、BR-01使用 `\ReportCode{...}` 保持整行。
4. 一级、二级标题进入真实目录，目录用点引线连接单个起始页码；有图时生成图录。前置目录页使用大写罗马数字，正文从1开始。让正文自然分页，章节标题与后续内容相连，参考文献条目保持完整，避免孤行说明占一页。
5. 多文件TeX项目优先使用可用的XeLaTeX，至少编译两轮并等待目录和交叉引用稳定；用另一个输出工具时按同样的可观察版式核对。若用户指定Word等格式，保留其可编辑文件格式并应用同一组排版参数。
6. 编译或导出后执行 `scripts/check_pdf.py <PDF>`，再按[版式规范中的验收项](references/format.md#验收)渲染检查所有页。脚本只核对部分PDF结构，目视复核覆盖目录、字体、图中文字、跨页表和页眉页脚。

运行环境：新建脚本只需Python 3标准库；PDF检查脚本需pypdf。TeX底稿使用XeLaTeX、ctex及序言中列出的宏包；根据可用环境检查字体和编译器，不假定新机器已具备它们。

## 表达

使用专业、连贯的中文，直接陈述问题、方法、结果与依据。合并重复说明，技术范围集中交代；具体业务中的必要限制和异常处理保留。来源事实、设计选择与已验证结果各有依据，缺失信息不补造。

## 交付

交付用户指定的文档和必要的可编辑源文件。说明实际完成的版式与验证，不声称测试脚本已经证明所有视觉细节。技能目录中的示例和校标属于个人模板资源，不要求额外发布、创建网站或安装插件。
