# 中南大学 Word 报告版式

沿用原参考TeX的整份文档版式，将其落实为可编辑的Word内容。当前任务决定题目、研究材料与章节；示例只展示格式，不提供研究事实。

## 资料与入口

- 排版前读[Word版式规范](references/format-word.md)。其中给出实际行距、封面结构、样式和分节页码。
- 使用[可编辑底稿](assets/report-template.docx)，或运行 `scripts/new_report.py --out <新文件.docx> --title <题目>` 创建带元数据的新文件，参数见 `--help`。正文可通过[内容块输入](references/authoring.md)生成，再用原生Word编辑。
- 用户要求沿用本人署名时读[个人信息规则](references/personal-profile.md)；新信息优先，教师按课程填写。
- 仅在当前报告含系统模型图时读[模型图约定](references/system-diagrams.md)，不把旧项目的业务内容带入新报告。

## 制作与修改

1. 保留用户已确定的内容、结构和交付格式。修改既有Word报告时在副本中调整样式、节、图表与必要的排版；新建脚本拒绝覆盖已有文件。正式报告替换底稿全部示例，处理必要的署名缺项。
2. 全文竖向A4，中文正文宋体12pt、固定26pt行距、首行24pt、段前后0。这里的26pt对应TeX中20pt名义行距乘ctex的1.3倍效果；Word固定20pt或简单设置1.3倍不会得到同样结果。
3. 章节使用Heading 1/2/3与原生多级编号，编号至三级、目录仅前两级。封面题目、摘要、目录和图录标题与章节样式分开。正文、署名、表格与题注保持可编辑，不能把整页报告转为图片。
4. 封面、前置页、正文分节。封面无页眉页脚，目录和图录连续用大写罗马页码，正文重启阿拉伯1。页眉采用校徽、两行简称与署名，页脚使用PAGE域。正文、标题及超链接黑色，校标保留原图颜色。
5. 图按竖向页面布局，图片与图题同页；图中文字可读，编号用SEQ，正文图号引用用书签与REF。表用三线结构、无竖线，跨页重复表头，短ID保持整行；长单元格正常换行。保留原生可编辑图形时如实说明，嵌入图片不等于图内部对象可编辑。
6. 目录、图录与交叉引用使用可更新的域。修改后更新所有相关域、重新分页并保存，不能只设置“打开时更新”就视为已经完成。无图不留空图录，校标不计为报告图形。
7. 运行 `scripts/check_docx.py <文件.docx>` 后，按[域更新与验收](references/verification.md)刷新、渲染并检查全部页面。结构检查不能证明目录页码新鲜或视觉排版正确，检查实际交付的最新版。

有Windows Word时可用 `scripts/update_fields.ps1 -Path <文件.docx> -PdfOutput <内部校验.pdf>` 更新和保存域；PDF参数可省略。其他环境使用可用的Word/LibreOffice更新工具并复核分页。环境不足时保留可编辑源文件，明确未完成的验证，不把手工冻结目录描述为自动目录。

## 表达与交付

专业、流畅地说明问题、方法、结果和依据，合并重复说明，保留有业务意义的条件与异常。使用实际材料，区分资料事实、设计选择和已验证结果；未知数据不补造，不默认加版本、年月装饰或课程项目标签。

交付用户要求的.docx及必要附件；渲染PNG和校验PDF留作内部验证，用户需要时再提供。运行脚本使用可用的Python 3：生成需python-docx和Pillow，结构检查需lxml；Windows域更新需安装的Word，其他环境不假定具有它。技能不附带网站发布、联网提交或插件安装义务。
